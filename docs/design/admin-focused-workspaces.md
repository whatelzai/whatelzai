# Focused Admin workspaces

Purpose: show the next useful action, with revenue and relationship tools within one click.

## Content decisions

- Overview answers: what deserves my next sprint this week? Keep weekly commitments and daily routines. Event operational details live in AI Business rather than repeating on Overview.
- AI Business answers: what moves my offers and relationships forward? Keep Events (attendees/sales, event planning), People (invites/follow-ups, newsletter), Proof (testimonials, event media), Products (playbook, paid offers). Occasional website, profile, brand, portfolio and technical tools remain under More tools; routes and records are retained.
- Network Marketing answers: who needs attention? Lead with Leads and Team management; activities/catalogue and member administration follow. Culture and calendar access move under More tools.
- Day Job retains its actual focus, deadlines and blockers. No invented work or sales metrics.
- Personal and Settings have no redundant workspace label or selector in the header.

## Taste direction

Accent ladder, seed 720896900; existing type, logo and navigation retained. Pale accent surfaces and compact outline icons identify workspaces: robot/yellow AI, network/purple relationships, sun/orange Day Job. Purple is an explicit user brand choice overriding the skill's default palette preference. No photographs or invented data added. Identity persists in greyscale through icon, label and active-state position. Main reading surfaces remain neutral in both themes.

Shared tokens are scoped to the Admin workspace wrapper, so member/public styles are unaffected. The brand mark stays yellow. Loading feedback, streaming sections, dynamic event tools, owner checks and timetable rules are retained. Event media deep-link initializes only the Media tool, never the camera.

## Visual review

Used the shared production navigation, preferences, theme wrapper and AdminArea components in temporary local fixtures with only navigation copy (no private data). Inspected 390, 768 and 1440 widths using CUA, including workspace menu, Personal header, purple/orange identity and dark mode. Fixed the mobile wrap of the attendee link and collapsed the brand text for the long Network Marketing selector at narrow widths. Fixtures are removed before release.

Critique: compact directory has one shared grid, clear section labels/icons and no metric tiles. Figures and focus are supplied by existing server components, not fixture numbers. Actual authenticated data pages were not browser-tested in this local fixture. Taste lint: zero failures; menu-shadow warning accepted because the menu is a floating overlay. Browser inspector script was not run because browser automation must use CUA; equivalent viewport review performed through CUA instead. No before/after numerical inspector score is claimed.
